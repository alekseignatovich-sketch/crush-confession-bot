# 💘 Crush Confession Bot — Анонимные признания ко Дню святого Валентина

![Valentine's Day Bot Banner](https://via.placeholder.com/1200x400/ff4d6d/ffffff?text=💌+Анонимные+признания+14+февраля)

> **100% анонимно** — получатель видит только бота, а не отправителя ❤️

Бот для романтических признаний, валентинок и анимированных стикеров. Отправляй признания крашу без страха быть отвергнутым — твоя личность остаётся в секрете!

---

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 💌 **Анонимные признания** | Отправляй текст, фото, голосовые — получатель не узнает отправителя |
| ❤️ **Анимированные стикеры** | 20+ валидных стикеров с сердечками и романтическими эмодзи |
| 💌 **Генерация валентинок** | Романтичные, смешные, милые и игривые сообщения на русском |
| 🔒 **Полная анонимность** | Получатель видит только сообщение от бота — без указания отправителя |
| ⏱️ **Антиспам** | Защита от флуда: 1 признание в минуту на пользователя |
| 📱 **Простой интерфейс** | Минималистичные кнопки без лишних элементов |

---

## 🚀 Как использовать

1. Открой бота: [@crushhhhconfessionbot](https://t.me/crushhhhconfessionbot)
2. Нажми **/start**
3. Укажи получателя:
   - Перешли любое его сообщение, **ИЛИ**
   - Напиши `@username`
4. Выбери контент:
   - 💝 Только стикер
   - 💌 Только валентинка
   - 💕 Стикер + валентинка
5. Подтверди отправку → признание улетело! ✨

> ⚠️ **Важно:** Получатель должен написать боту `/start` хотя бы один раз, иначе Telegram не позволит доставить сообщение.

## ⚙️ Развертывание (для разработчиков)

### Требования
- Python 3.10+
- Telegram Bot Token ([@BotFather](https://t.me/BotFather))
- Docker (опционально)

### Быстрый старт

```bash
# 1. Клонируй репозиторий
git clone https://github.com/your-username/crush-confession-bot.git
cd crush-confession-bot

# 2. Создай .env файл
cp .env.example .env

# 3. Заполни переменные окружения
nano .env
